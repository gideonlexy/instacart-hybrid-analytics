# Instacart Hybrid Analytics Platform
End-to-end enterprise analytics + data science platform on 3M+ Instacart
orders. Demonstrates AWS data lake, Databricks medallion architecture,
Snowflake warehouse, dbt analytics engineering, ML models, forecasting,
causal inference, Streamlit deployment, and Airflow orchestration.
